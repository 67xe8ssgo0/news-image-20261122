# Sum up 22 November's world news in one image

An entry for the make.fun bounty "Sum up 22 November's world news in one image".

`main.py` is a Python program (Pillow) that writes one 1024x1024 front-page
image of the day's world news: `news-2026-11-22.png`.

## Run

```sh
pip install Pillow
python3 main.py
```
